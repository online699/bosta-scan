# مسح الشحنات (بدون CMD)

ملف واحد `index.html` بيشتغل في المتصفح. كل براند ليه شركة شحن ومفتاح API خاص بيه، وبتظبطهم من زرار **الإعدادات** جوه الصفحة.

## النشر على GitHub (من الموقع، بدون أوامر)
1. على github.com اعمل Repository جديد (Public أو Private حسب خطتك).
2. اضغط **Add file > Upload files** وارفع `index.html` واعمل Commit.
3. **Settings > Pages > Source: Deploy from a branch > main / (root) > Save**.
4. بعد دقيقة الرابط هيكون `https://اسمك.github.io/اسم-الريبو/`.

## ربط كل براند بشركة شحن
افتح الصفحة، اضغط **إعدادات البراندات وشركات الشحن**، وفي كل براند اختار الشركة وحط المفتاح بتاعه واضغط **حفظ**.
- **Bosta:** جاهز. بيستخدم `GET /api/v2/deliveries/business/{tracking}` والمفتاح بيتبعت في `Authorization`.
- **شركة أخرى:** حط رابط التحقق وفيه `{tracking}`، وبادئة المفتاح لو لازم. التحقق هنا بيعتمد على إن الرد HTTP 200 بس، ومش بيقرا بيانات الشحنة. لازم تراجع توثيق الشركة.
- **بدون تحقق:** بيسجل ويمنع التكرار بس.

## لو ظهرت رسالة CORS (مهم)
المتصفح ممكن يمنع الاتصال المباشر بشركة الشحن، ومقدرتش أتأكد من ده مع بوسطة. الحل بدون CMD:
1. افتح dash.cloudflare.com، ثم **Workers & Pages > Create > Worker**.
2. الصق محتوى `worker.js` وعدّل `ALLOWED_ORIGINS` برابط موقعك واضغط **Deploy**.
3. انسخ رابط الـ Worker وحطه في خانة **رابط Proxy** لكل براند.

## تنبيهات
- الشحنات والمفاتيح بتتحفظ في **متصفح الجهاز ده فقط**. جهاز تاني أو مسح بيانات المتصفح = داتا مختلفة أو ضايعة. استخدم **نسخة احتياطية** كل يوم. النسخة لا تتضمن المفاتيح.
- المفتاح مش في كود GitHub، لكن أي حد يستخدم نفس المتصفح يقدر يشوفه. استخدم Read Only.
- لو عاوز أكتر من جهاز يشوفوا نفس الداتا، محتاج قاعدة بيانات (زي Supabase) وده الخطوة الجاية.
